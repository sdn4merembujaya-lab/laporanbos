Tambah Sekolah

Halaman ini hanya membuat kode. Sekolah baru baru berlaku setelah isi akses.js di GitHub diganti dengan hasil di bawah.

1. Cek nama sekolah
Sudah terdaftar atau belum?

2. Tambah sekolah baru
Satu nama sekolah per baris.

3. Pasang di GitHub
  1. Buka repo, klik file akses.js, lalu klik ikon pensil (Edit).
  2. Hapus seluruh isinya, tempel hasil yang disalin, klik Commit changes.
  3. Tunggu 1 sampai 2 menit, lalu muat ulang aplikasi.
